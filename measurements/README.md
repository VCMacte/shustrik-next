# Снятые на устройстве числа

По файлу на сессию, только агрегаты: кадры, ровность хода, инференс, частота
поз, вызовы отрисовки. Никогда — сырые точки скелета: это движения ребёнка, а
папка попадает в публичный репозиторий.

Пороги, с которыми эти числа сравниваются, записаны ЗАРАНЕЕ в
`docs/superpowers/specs/2026-10-21-architecture.md`. Менять потолок задним
числом под полученное число — ровно то, от чего запись защищает.
