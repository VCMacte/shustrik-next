# Журналы с телефона

Сюда кладутся выгруженные журналы (`*.json`). В репозиторий они не уезжают
намеренно: репозиторий публичный, а журнал — запись о том, как и когда ребёнок
играл в своей комнате. Это не формальность, а правило, перенесённое из
`run-game` вместе с логикой.

Разбор — `node ../run-game/tools/log-report.mjs <файл>`: журнал этого проекта
пишет поля теми же именами, иначе сравнивать с базовой линией нечем.
